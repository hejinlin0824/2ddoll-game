# 2Doll Game — 魂斗罗·布娃娃

一个 2D 魂斗罗风格的射击游戏,主角是 **主动式布娃娃(active ragdoll)**:
planck.js 物理驱动的关节小人,走、跳、趴、双武器射击、鼠标瞄准,
外加一个**武器与装备设计器**(拼枪、标握点、定制头盔/防弹衣,游戏内实时生效)。

技术栈:Vite 6 + 原生 ES 模块 + Canvas 2D + [planck.js](https://github.com/piqnt/planck.js)(Box2D 移植)。

## 运行

```bash
npm install
npm run dev
# → http://127.0.0.1:5199/game.html        游戏
# → http://127.0.0.1:5199/weapon-editor.html  武器与装备设计器
```

## 玩法系统

- **主动式布娃娃**:躯干是物理胶囊,四肢是带限位的关节电机伺服——所有动作都是物理解算,
  不是动画;R 键关掉电机可以看纯布娃娃瘫倒。
- **熟练度**:越练越准——后坐力热量积累更快消退、散布与枪口上跳随熟练度衰减(localStorage 持久化)。
- **皮肤工坊(自绘主角)**:自己画 头/躯干/大臂/小臂/大腿/小腿 六件套简笔画(白底),
  上传自动抠白底+裁边,贴到物理布娃娃上——跑步/翻滚/死亡布娃娃全都自动正确;
  装备照常叠在皮肤外面,没画的部件自动用回程序绘制。
- **武器与装备设计器**:拼一把自己的枪、标记前后手握点和枪口;定制头盔/防弹衣;
  保存后游戏内实时穿戴生效。
- **武器轮盘(GTA 式)**:按住 Tab 唤起,世界进入子弹时间(全员约 8% 速度慢动作);
  无光标扇区选择,鼠标方向即高亮;T 切换武器/装备两层;当前装备标「当前」,
  悬停即「卸下/选中」,松开 Tab 实时生效。武器层 = 整圆 7 份(5 预设枪 + 常备手枪 + 盾牌)。
- **武器词条**:每把枪有射速/威力/弹匣/散布/弹丸数/初速/射程/后坐力/枪声等属性
  (AK 600发/分 vs M4 820发/分,枪声也各自不同);打空自动换弹;未来刷宝词缀在此扩展。
- **霰弹枪**:一次 8 颗弹丸扇形散射(散布词条决定角度);**狙击枪**:站桩狙击,
  准星处有圆形放大镜(2.6x,可拖动侦察,越远越模糊模拟有效射程),开枪是瞬时贯穿的
  激光光束,沿途敌人都受伤、第一个最疼。
- **枪感**:子弹曲线加速越飞越快,连发时人物随每枪后坐力高频震颤。
- **防弹盾牌**:武器轮盘里举起,只能配手枪(一手盾一手枪),挡敌方子弹,耐久打光会碎;
  **近战 V**:枪托前捅,举盾时是盾牌冲撞,能把敌人推开。
- **装备数值**:头盔/防弹衣带防御值,是未来敌人伤害系统的减伤系数。

## 结构

```
game.html             游戏
weapon-editor.html    武器与装备设计器
level-editor.html     关卡设计器(主菜单「我的关卡」)

src/game/core/        分辨率与物理常量
src/game/domain/      纯数据层:gunPresets(词条/预设)/ affixes(词缀)/ inventory(经济)/ waves(波次)
src/game/entities/    player(布娃娃主角)/ enemies(Dummy=AI 驱动的 Player)
src/game/systems/     audio / input / camera(含方向性后坐)/ feel / fx / combat / hud
src/game/ui/          wheel(轮盘)/ backpack(背包)/ menu(主菜单)
src/game/world/       level(地形/碰撞/自定义关卡)
src/designer/         设计器页面专用(editor / studio / levelEditor)
AGENT.md / ARCHITECTURE.md  架构细节与踩坑记录(改代码前必读)
```
