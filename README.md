# 2Doll Game — 魂斗罗·布娃娃

一个 2D 魂斗罗风格的射击游戏,主角是 **主动式布娃娃(active ragdoll)**:
planck.js 物理驱动的关节小人,走、跳、趴、双武器射击、鼠标瞄准,
外加一个**武器与装备设计器**(拼枪、标握点、定制头盔/防弹衣,游戏内实时生效)。

技术栈:Vite 6 + 原生 ES 模块 + Canvas 2D + [planck.js](https://github.com/piqnt/planck.js)(Box2D 移植)。

## 运行

```bash
npm install
npm run dev
# → http://127.0.0.1:5199/game.html        游戏
# → http://127.0.0.1:5199/weapon-editor.html  武器与装备设计器
```

## 操作

| 按键 | 功能 |
|---|---|
| A / D | 前后走 |
| W | 跳 |
| S | 趴下 |
| 鼠标 | 瞄准(子弹直射光标点) |
| 空格 / 左键 | 射击 |
| Q / 1 / 2 | 切换 主武器 / 手枪 |
| R / E | 布娃娃测试 / 复位 |
| B | 物理线框 |

## 玩法系统

- **主动式布娃娃**:躯干是物理胶囊,四肢是带限位的关节电机伺服——所有动作都是物理解算,
  不是动画;R 键关掉电机可以看纯布娃娃瘫倒。
- **熟练度**:越练越准——后坐力热量积累更快消退、散布与枪口上跳随熟练度衰减(localStorage 持久化)。
- **武器与装备设计器**:拼一把自己的枪、标记前后手握点和枪口;定制头盔/防弹衣;
  保存后游戏内实时穿戴生效。
- **装备数值**:头盔/防弹衣带防御值,是未来敌人伤害系统的减伤系数。

```
src/game/player.js    主动式布娃娃主角(物理 + 双臂 IK + 姿态 + 开火)
src/game/level.js     地形与碰撞分类
src/game/gunPresets.js 枪械/装备数据格式与预设
src/game/editor.js    设计器逻辑
AGENT.md              AI 接手须知(架构细节与踩坑记录)
```
